# Spellbook

Small, self-contained scripts for specific tasks. Each lives in its own directory with a README.

**Updating installed scripts:** Install adds a shell alias to the script file — it does not copy anything elsewhere. Pull or edit the script in its directory and changes apply on the next run. Reinstall only if you move the script to a new path.

## Scripts

- [mov2mp4](mov2mp4/) — Convert MOV to MP4 (max 1080p, smaller file size)
